Урок 4: Современный Flexbox

Мощный инструмент CSS для выравнивания элементов по горизонтали и вертикали.

display: flex;

Превращает обычный вертикальный список элементов в гибкую строку.

display: flex;

justify-content

Выравнивает элементы по горизонтали (по главной оси): по центру, по краям или с равными отступами.

justify-content: space-between;

Главный секрет адаптивности

Благодаря свойствам Flexbox элементы на вашем сайте автоматически подстраиваются под размер экрана смартфона или компьютера без сложных вычислений.
