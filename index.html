Что такое HTML?

HTML (HyperText Markup Language) — это скелет любого сайта. С помощью тегов мы объясняем браузеру, где заголовок, где текст, а где кнопка.

<h1> — Заголовок

Используется для главных названий на странице. Самый крупный текст.

<h1>Привет, мир!</h1>

<p> — Абзац

Обычный текстовый блок для статей, описаний и заметок.

<p>Это простой текст.</p>

<a> — Ссылка

Позволяет переходить на другие страницы. Адрес пишется в атрибуте href.

<a href="#">Нажми меня</a>
